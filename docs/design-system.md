# Design System

## Typography

- Primary font: Geist Sans
- Secondary font: Geist Mono
- Usage: large headlines use Geist Sans, while small UI labels and code-like accents use Geist Mono

## Color Palette

- Background: #050505
- Primary text: #ffffff
- Muted text: #a3a3a3
- Surface: #111111 / slate-800 for cards and UI panels
- Contrast accent: #ffffff

## Layout Principles

- Sections use full-height layouts with generous vertical spacing.
- The interface favors minimal structure with strong typography and negative space.
- Core spacing is driven by Tailwind utilities such as px-6, px-4, p-8, and gap-based layouts.

## UI Patterns

- Header: a pill-shaped, semi-transparent navigation bar with rounded edges
- Buttons: soft border treatment with subtle hover transitions
- Cards: rounded surfaces with dark backgrounds and light text
- Motion: low-noise transitions that support the narrative rather than overpower it

## Visual Direction

The current design language is dark, editorial, and immersive, with a premium feel built around bold typography and controlled animation.
